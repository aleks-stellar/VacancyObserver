# Проект VacancyObserver

Проект для поиска и фильтрации вакансий с использованием API HeadHunter (https://hh.ru).

## Описание

### Проект позволяет:

- искать вакансии по ключевым словам;  
- сохранять результаты в JSON-файл;  
- проводить валидацию вакансий;
- фильтровать вакансии по зарплате и ключевым словам;
- удалять вакансии из файла;  
- выводить топ-N вакансий по зарплате.

### Структура проекта

Структура проекта включает в себя четыре части:
- работа с API (модули base_api и hh_api) - папка api;
- работа с вакансиями (модуль base_vacancy) - папка vacancy;
- работа с файлами, хранящими информацию о вакансиях (модули file_worker и json_worker) - папка connector;
- пользовательский интерфейс (модуль interface) - папка user_interface.

### Подробно о модулях

- модуль base_api реализует абстрактный класс BaseAPI;
- модуль hh_api реализует класс HeadHunterAPI для работы с API HeadHunter;
- модуль base_vacancy реализует абстрактный класс BaseVacancy для работы с вакансиями;
- модуль file_worker реализует абстрактный класс FileWorker;
- модуль json_worker реализует класс JSONWorker для работы с файлом типа JSON;
- модуль interface реализует пользовательский интерфейс (функция user_interface).

## Основные используемые версии и библиотеки

- Python 3.12  
- requests  
- json
- abc (абстрактные классы)

## Установка

1. Клонируйте репозиторий:
```commandline
git clone https://github.com/aleks-stellar/VacancyObserver
```
2. Установите зависимости:
```commandline
poetry install
```

## Использование

1. Запустите модуль main в корневой директории.
2. Следуйте инструкциям.

## Тестирование
